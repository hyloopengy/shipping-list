发货清单 Win10 安装说明
========================

一、安装 Python

安装 64 位 Python 3.12。
安装时必须勾选：Add Python to PATH。

二、复制文件

把整个“发货清单”文件夹复制到固定目录，例如：

D:\发货清单

三、启动

双击 start-windows.bat。

第一次运行会创建运行环境并从网络下载依赖，可能需要几分钟。
Windows 防火墙询问时，只允许“专用网络”。

本机访问：

http://127.0.0.1:8765

四、其他内网电脑访问

在服务器电脑打开命令提示符，执行：

ipconfig

找到 IPv4 地址，例如 192.168.1.50。
其他电脑访问：

http://192.168.1.50:8765

五、数据位置

数据库：data\packing.db
自动备份：data\backups
上传文件：data\uploads

请定期把整个 data 文件夹复制到另一块磁盘或公司共享盘。

六、注意事项

1. 服务器电脑必须保持开机，不能进入睡眠。
2. 不要把 8765 端口开放到公网。
3. 更新程序前先备份 data 文件夹。
4. 关闭标题为“发货清单”的服务窗口即可停止网站。
